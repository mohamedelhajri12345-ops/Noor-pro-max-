# Noor - app-ads.txt Setup

## Purpose
This file explains the preparation required for app-ads.txt verification for Noor.

## Required steps
1. Create a developer website connected to the app store listing.
2. Host a public file at:

```
https://your-domain.com/app-ads.txt
```

3. Add the authorized advertising sellers provided by your advertising partners (including Start.io) using the exact lines from their publisher dashboard/documentation.

## Noor App Information
- App Name: Noor
- Package Name: com.noorpromax
- Start.io App ID: 207270163

## Store Release Checklist
- Privacy Policy URL added.
- Developer website added.
- Ads disclosure added.
- Data safety information completed.
- Test ads before production release.

## Notes
Do not copy unknown seller lines into app-ads.txt. Each advertising network must provide its official authorized seller entry.

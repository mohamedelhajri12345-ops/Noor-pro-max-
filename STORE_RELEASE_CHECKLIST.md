# Noor Release Checklist

## Android Builds

- App name: Noor
- Package name: com.noorpromax
- APK: direct installation and alternative stores
- AAB: Google Play submission

## Before publishing

- Privacy policy added
- App icon ready
- Screenshots prepared
- Store description prepared
- Permissions reviewed
- Ads integration tested

## Supported distribution targets

Prepare release packages for Android marketplaces and direct APK distribution platforms.
